# Reusable LLM Frontend

A Next.js 16 App Router starter that keeps backend communication on the server.
It uses shadcn/ui primitives, granular React Suspense boundaries, and a Server
Action for generation requests.

## Setup

```bash
cp .env.example .env.local
npm install
npm run dev
```

Run the FastAPI app on `http://127.0.0.1:8000`, then open
`http://localhost:3000`. Change `BACKEND_URL` in `.env.local` if the API lives
elsewhere, and keep `BACKEND_API_PREFIX` aligned with the backend's
`API_V1_PREFIX`. Do not rename either setting with a `NEXT_PUBLIC_` prefix: the
backend location is intentionally server-only.

The browser will request HTTP Basic credentials. Both environment settings are
required; the local example is `local` / `local-development-only`. Set
`BASIC_AUTH_USERNAME` and
`BASIC_AUTH_PASSWORD` to the same values in both frontend and backend
environments. Never deploy with the local example, never expose either value
through a `NEXT_PUBLIC_` variable, and use HTTPS outside local development
because Basic credentials are encoded rather than encrypted.

Metadata reads time out after five seconds by default. Generations have a
separate 60-second budget because real providers are slower; tune
`BACKEND_READ_TIMEOUT_MS` and `BACKEND_GENERATION_TIMEOUT_MS` in `.env.local`.

## Structure

- `src/lib/backend.ts` is the only FastAPI HTTP client and imports `server-only`.
- `src/proxy.ts` protects page and Server Action requests while allowing Next.js
  static/image assets to load without credentials.
- `src/lib/auth.ts` rechecks each protected server operation and forwards the
  incoming Authorization header to FastAPI. Backend health remains public;
  configuration and generation are protected.
- Each metadata card renders a static shell and places its async detail
  component inside a separate Suspense boundary.
- `src/app/actions.ts` validates form input and performs generation requests on
  the server.
- `src/components/prompt-form.tsx` is the small client boundary needed for form
  pending and result state.
- `src/components/ui/` contains components generated by the shadcn CLI.

Keep static headings and descriptions outside Suspense when adding features.
For each independent server data source, colocate its fetch in an async Server
Component and provide a size-matched shadcn `Skeleton` fallback.

The backend's generation rate limit is displayed in the configuration card. If
FastAPI returns `429 Too Many Requests`, the Server Action surfaces the
`Retry-After` delay so the user knows when to submit again.

HTTP Basic authentication is deliberately a small starter boundary with one
shared credential and no login, logout, roles, or session revocation. Replace it
with a production authentication system before adding real users or sensitive
data.
